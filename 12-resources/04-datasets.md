# Benchmark Datasets & Data Repositories

Authoritative repositories for research benchmarking, fine-tuning, and evaluation.

## Multi-Modal & Vision
1. **ImageNet (ILSVRC)**: 14M+ annotated images across 20k categories; benchmark for visual representation learning.
2. **MS COCO (Common Objects in Context)**: 330k images with 1.5M object instances for bounding box detection, keypoints, and segmentation.
3. **LAION-5B / DataComp**: Web-scale multimodal image-text dataset for contrastive vision-language pretraining.

## Language & Code
4. **Common Crawl**: Multi-petabyte archive of web crawl data; foundational pretraining corpus for modern LLMs.
5. **The Pile / FineWeb**: Carefully filtered and deduplicated high-quality web text for open foundation models.
6. **SWE-bench**: 2,294 software engineering problems pulled from real GitHub issues and pull requests to benchmark autonomous coding agents.
7. **SQuAD (Stanford Question Answering Dataset)**: 100k+ reading comprehension question-answer pairs over Wikipedia articles.

## Tabular & Classical
8. **UCI Machine Learning Repository**: 600+ curated classical datasets (Iris, Adult Census, Wine Quality, Credit Card Fraud).
9. **Kaggle Datasets**: Broad community repository of industrial competition datasets and tabular challenges.
