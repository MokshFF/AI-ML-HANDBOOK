# Machine Learning & AI Python Libraries

Curated ecosystem breakdown of essential, production-proven Python libraries.

## Core Compute & Tensors
- `numpy`: The foundational library for multi-dimensional arrays, linear algebra, and Fourier transforms.
- `scipy`: Advanced scientific algorithms, statistical tests, optimization, and signal processing.
- `torch`: Deep learning framework featuring dynamic computational graphs, TorchScript, and CUDA acceleration.
- `jax`: Autograd and XLA compilation for high-performance machine learning research on GPUs and TPUs.

## Classical ML & Data Processing
- `scikit-learn`: Industry standard for classical modeling, feature transformations, and cross-validation.
- `pandas` / `polars`: Tabular data manipulation (Polars delivers multithreaded Rust-backed performance).
- `lightgbm` / `xgboost` / `catboost`: Production-grade gradient boosted decision tree implementations.

## LLM, NLP & Generative AI
- `transformers`: Unified APIs for thousands of pre-trained models.
- `tokenizers`: Ultra-fast Rust-based tokenization engines.
- `peft`: Parameter-efficient adaptation (LoRA, AdaLoRA, Prefix Tuning).
- `bitsandbytes`: 8-bit and 4-bit quantization kernels for GPU acceleration.
- `diffusers`: State-of-the-art pretrained diffusion models for image and audio generation.
