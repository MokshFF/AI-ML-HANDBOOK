# Intermediate Projects (`09-projects/intermediate`)

Core deep learning, NLP, recommendation engines, and time-series forecasting implementations.

## Included Projects
| Project | Focus Area | Key Technologies |
| :--- | :--- | :--- |
| [**03. Image Classifier**](./03-image-classifier/) | Residual convolutional networks, visual data augmentation, top-1 accuracy | PyTorch, NumPy |
| [**04. NLP Sentiment Classifier**](./04-nlp-sentiment-classifier/) | Text tokenization, TF-IDF vectorization, polarity scoring | NumPy, Scikit-Learn |
| [**05. Recommendation System**](./05-recommendation-system/) | Matrix factorization, latent user/item embeddings, NDCG@K ranking | NumPy |
| [**06. Time-Series Forecasting**](./06-time-series-forecasting/) | Autoregressive lag features, seasonal harmonics, demand forecasting | NumPy, Pandas |

## Project Structure
Every project follows the production schema with `README.md`, `src/`, `notebooks/`, `tests/`, `requirements.txt`, and `.env.example`.
