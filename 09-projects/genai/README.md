# Generative AI Projects (`09-projects/genai`)

Applied Large Language Model systems, multi-tool agentic workflows, and multimodal applications.

## Included Projects
| Project | Focus Area | Key Technologies |
| :--- | :--- | :--- |
| [**10. RAG Chatbot**](./10-rag-chatbot/) | Document chunking, dense vector retrieval, grounded prompt synthesis, citations | NumPy, Pytest, Docker |
| [**11. AI Interview Trainer**](./11-ai-interview-trainer/) | Multi-turn mock interview simulation, dynamic questioning, scoring rubric | Python 3.11 |
| [**12. Multi-Tool AI Agent**](./12-multi-tool-ai-agent/) | ReAct Thought-Action-Observation loop, math calculator, knowledge lookup | Python 3.11, Docker |
| [**13. Multimodal AI Application**](./13-multimodal-ai-app/) | Vision-language dual encoder, cross-modal similarity search, visual Q&A | PyTorch |
| [**14. End-to-End LLM Application**](./14-end-to-end-llm-app/) | Semantic caching, token-bucket rate limiting, structured Pydantic schemas | Python 3.11, Docker |

## Project Structure
Every project follows the production schema with `README.md`, `src/`, `notebooks/`, `tests/`, `requirements.txt`, `.env.example`, and Dockerfile where appropriate.
