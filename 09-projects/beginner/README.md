# Beginner Projects (`09-projects/beginner`)

Foundational, end-to-end machine learning implementations focusing on tabular data, exploratory data analysis, feature engineering, and model validation.

## Included Projects
| Project | Focus Area | Key Technologies |
| :--- | :--- | :--- |
| [**01. House Price Prediction**](./01-house-price-prediction/) | Tabular regression, z-score scaling, one-hot encoding, Ridge regression | NumPy, Pandas, Scikit-Learn |
| [**02. Customer Churn Prediction**](./02-customer-churn-prediction/) | Binary classification, class imbalance, probability calibration, threshold tuning | NumPy, Pandas, Scikit-Learn |

## Project Structure
Every project contains:
- `README.md`: Problem, motivation, dataset, architecture, pipeline, installation, usage, evaluation, results, limitations.
- `src/`: Clean, modular production Python code.
- `notebooks/`: Interactive runnable Jupyter notebook.
- `tests/`: Automated unit tests via `pytest`.
- `requirements.txt`: Minimal reproducible dependencies.
- `.env.example`: Configuration and environment variables.
