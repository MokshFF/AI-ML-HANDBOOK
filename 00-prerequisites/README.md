# Prerequisites (`00-prerequisites`)

## Overview
Mathematical foundations, programming essentials, and data structures required for rigorous AI/ML engineering.

## Subtopics & Navigation
| Directory | Topic | Scope |
| :--- | :--- | :--- |
| [`python-for-ml/`](./python-for-ml/) | **Python For ML** | Essential Python programming constructs, typing, NumPy, Pandas vectorization, and efficiency patterns for machine learning pipelines. |
| [`math-linear-algebra/`](./math-linear-algebra/) | **Math Linear Algebra** | Vectors, matrices, linear transformations, eigenvalues, eigenvectors, SVD, and matrix decompositions fundamental to ML algorithms. |
| [`math-calculus-optimization/`](./math-calculus-optimization/) | **Math Calculus Optimization** | Multivariate calculus, gradients, Jacobians, Hessians, convex optimization, and gradient descent variants. |
| [`probability-statistics/`](./probability-statistics/) | **Probability Statistics** | Probability distributions, Bayes theorem, expectation, variance, hypothesis testing, MLE, and MAP estimation. |
| [`data-structures-for-ml/`](./data-structures-for-ml/) | **Data Structures For ML** | Algorithmic thinking, tree structures, graph representations, sparse matrices, and memory layouts essential for ML engineering. |

## Standard Directory Schema
Every topic directory in this module follows our standard five-component structure:
- `README.md` - Module introduction, learning objectives, and concept matrix
- `notebook.ipynb` - Reproducible, runnable interactive notebook
- `code/` - Clean, modular Python scripts and helper utilities
- `interview.md` - Technical screening questions, edge cases, and design discussions
- `references.md` - Research papers, textbooks, and documentation
