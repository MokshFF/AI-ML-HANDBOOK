# Deep Learning (`02-deep-learning`)

## Overview
Neural network architectures from perceptrons to transformers, optimization mechanics, and practical training techniques.

## Subtopics & Navigation
| Directory | Topic | Scope |
| :--- | :--- | :--- |
| [`fundamentals/`](./fundamentals/) | **Fundamentals** | Perceptrons, multi-layer perceptrons, forward propagation, backpropagation, loss functions, and activation functions. |
| [`cnn/`](./cnn/) | **CNN** | Convolutional layers, pooling, classic architectures (ResNet, EfficientNet, ConvNeXt), and spatial inductive biases. |
| [`rnn-lstm-gru/`](./rnn-lstm-gru/) | **RNN LSTM GRU** | Recurrent neural architectures, gated recurrent units, vanishing/exploding gradients, and sequence modeling. |
| [`attention-transformers/`](./attention-transformers/) | **Attention Transformers** | Scaled dot-product attention, multi-head self-attention, positional encodings, encoder-decoder architectures. |
| [`generative-models/`](./generative-models/) | **Generative Models** | Autoencoders, variational autoencoders (VAEs), generative adversarial networks (GANs), and diffusion models. |
| [`graph-neural-networks/`](./graph-neural-networks/) | **Graph Neural Networks** | Graph convolutions, node/edge embeddings, message passing neural networks, and relational graph reasoning. |
| [`training-tricks/`](./training-tricks/) | **Training Tricks** | Normalization strategies (LayerNorm, BatchNorm), weight initialization, learning rate schedulers, and regularization. |

## Standard Directory Schema
Every topic directory in this module follows our standard five-component structure:
- `README.md` - Module introduction, learning objectives, and concept matrix
- `notebook.ipynb` - Reproducible, runnable interactive notebook
- `code/` - Clean, modular Python scripts and helper utilities
- `interview.md` - Technical screening questions, edge cases, and design discussions
- `references.md` - Research papers, textbooks, and documentation
