# Speech & Audio Processing (`05-speech-audio`)

## Overview
Signal processing, speech recognition (ASR), speech synthesis (TTS), and audio representation models.

## Subtopics & Navigation
| Directory | Topic | Scope |
| :--- | :--- | :--- |
| [`audio-fundamentals/`](./audio-fundamentals/) | **Audio Fundamentals** | Waveforms, sampling rates, spectrograms, Mel-frequency cepstral coefficients (MFCCs), and Fourier transforms. |
| [`speech-recognition-asr/`](./speech-recognition-asr/) | **Speech Recognition ASR** | Acoustic modeling, CTC loss, Whisper architecture, and speech-to-text pipeline engineering. |
| [`speech-synthesis-tts/`](./speech-synthesis-tts/) | **Speech Synthesis TTS** | Text-to-speech architectures (Tacotron, FastSpeech, VITS), vocoders, and acoustic alignment. |
| [`audio-classification/`](./audio-classification/) | **Audio Classification** | Audio event detection, environmental sound recognition, and speech emotion recognition. |
