# Interview Preparation (`10-interview-prep`)

## Overview
Technical screening blueprints, coding challenges from scratch, theory deep dives, and system design mock interviews.

## Subtopics & Navigation
| Directory | Topic | Scope |
| :--- | :--- | :--- |
| [`coding-questions/`](./coding-questions/) | **Coding Questions** | Data structures, algorithms, vector operations, and ML algorithm implementations from scratch. |
| [`cheat-sheets/`](./cheat-sheets/) | **Cheat Sheets** | Dense, quick-reference summaries of formulas, hyperparameter behaviors, model architectures, and CLI commands. |
| [`system-design-interviews/`](./system-design-interviews/) | **System Design Interviews** | Frameworks, step-by-step interview blueprints, trade-off analysis, and capacity estimation techniques. |
